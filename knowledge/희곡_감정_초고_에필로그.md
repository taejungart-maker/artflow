## 에필로그 — 빈 액자

```
(수장고. 손전등 빛.
소해, 혼자다. 무릎 위의 낡은 화첩 — 빈 장이 펼쳐져 있다.
가만히, 덮는다.

봉인된 캔버스 앞에 선다.
서류철을 연다.)
```

**소해** (읽는다) 상태, 봉인. 전시 불가. 사유 —

```
(빈 칸.
소해, 볼펜을 꺼낸다. 사유 칸 위에 볼펜 끝을 댄다.
— 쓰지 못한다.
볼펜을 넣는다.)
```

```
(소해, 노끈에 손을 댄다.
프롤로그에서 멈췄던 그 자리.
이번에는 — 푼다.
천이 흘러내린다.

빈 액자.
소해, 그림을 본다. 오래 본다.
그림도, 그녀를 볼 것이다 — 같은 얼굴이니까.)
```

**소해** (그림에서 눈을 떼지 않은 채) ……선생님.
그림이…… 뭐예요.

```
(수장고 한켠에 — 1991년의 빛이 한 조각 켜진다.
마당 수돗가. 인화, 붓을 씻고 있다.)
```

**인화** (씻으며) ……오늘 치 붓 씻는 거.

```
(소해, 잠자코 듣는다.)
```

**인화** (붓을 털며) 내일 또 씻고.

```
(1991년의 빛, 꺼진다.
소해, 혼자.

액자를 두 손으로 든다.
살살. 오래 삭은 종이를 다루듯.

무전기 지직 — )
```

**무전기(소리)** 윤 선생님, 점검 다 끝나셨어요? 오늘까지 목록 넘겨야 하는데, 91-0430 하나만 비었어요.

**소해** (액자를 든 채) ……네. 지금 그 앞이에요.

**무전기(소리)** 삼십 년째 봉인이던데, 그거. 어떻게 할까요. 폐기로 올릴까요?

```
(사이.
소해, 액자를 안은 채 객석을 향해 돌아선다.
객석에, 빛.)
```

**소해** ……보류요. 얘는, 제가 맡을게요.

```
(긴 사이.
소해와 빈 액자와, 불 켜진 객석.
암전.)
```

```
(어둠 속에서 — 지직.
라디오 켜지는 소리. 삼십 년 만이다.

양희은, 〈사랑 그 쓸쓸함에 대하여〉.

불이 들어오면 — 무대 위엔 빈 액자와 빈 새장.
그리고 라디오만, 켜져 있다.

배우들, 하나씩 나와 인사한다.
인화 역 배우, 마지막에 나온다.
라디오 옆을 지나다 — 잠깐 멈춘다.
소리를, 조금 키운다.
인사한다.

노래는 관객이 극장을 다 나갈 때까지 흐른다.)
```

## 작가 노트 (에필로그)

- **마지막 시퀀스 — ✅ 최종 확정 (2026-08-17 배우님 낭독 판정 "이 안이 너무 좋아"):** 무전기 증축 + **"……보류요. 얘는, 제가 맡을게요."**
  - 판정 이력: "당신이라면, 겁니까?"(객석 빛과 이중) / 변주 U 밥 호명(각운 인플레) 탈락 → 모루안 "제가 더 볼게요" → 배우님 되물음 2회("뭘 더 본다는 얘기지?") = 사망 — '보다'는 동사가 목적어 없이 떠 있었다
  - **진짜 문제는 대사가 아니라 상황 전달 (배우님 진단):** "실사·처리 항목" 행정어로는 관객이 수장고 점검 상황을 모른다 → **무전기 증축** — 라디오가 페놀을 설명했듯 무전기가 상황을 공짜로 설명. "폐기로 올릴까요?"로 그림의 목숨이 걸린 질문 생성. "네. 지금 그 앞이에요"는 무대 사실 그대로의 보고
  - 채택안: 폐기도, 30년의 방치도 아닌 제3의 답. "맡다" = 오해 불가능한 인수. **"얘"** = 인화가 그림들을 부르던 호칭("얘가 아직 대답을 안 했어"·"얘들은 술 못 해")의 상속 — 서류 번호 91-0430이 마지막 문장에서 "얘"가 되는 순간, 인화의 세계관이 30년을 건너 소해에게 전해진다
- **AD 개선안 적용:** 소해의 "그게 다예요?" 삭제 — 유도 질문 티 제거, 인화가 혼자 "내일 또 씻고" 덧붙임 (정본 2-3 개선 검토 이행)
- **사유 칸 회수:** 볼펜을 댔다 넣는 동작만 — 4장 "기록할 칸이 없습니다"를 아는 관객의 몫 (실물 윙크 4조건 충족: 프롤로그에서 보인 실물, 놓쳐도 무사)
- **노끈 수미상관:** 프롤로그에서 닿기만 한 손이 에필로그에서 푼다 — 극 전체가 이 한 동작의 완성
- **"살살. 오래 삭은 종이를 다루듯"** — 4장 인화의 취급 주의(AW)를 소해가 물려받음. 그녀의 법이 상속되는 지문
- **1인 2역의 비밀 완성:** "그림도, 그녀를 볼 것이다 — 같은 얼굴이니까" — 대사 0, 지문과 캐스팅이 말함
- 커튼콜 포함 = 대본의 마지막 페이지까지 설계 완료
