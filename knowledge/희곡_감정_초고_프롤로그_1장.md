## 프롤로그 — 수장고

```
어둠.
소리들이 겹겹이 쌓인다 — 도장 찍는 소리. 타자기. 서류 넘기는 소리.
기계처럼 반복되다가, 뚝. 끊긴다.

손전등 불빛 하나가 어둠을 가른다.

수장고. 윤소해, 태블릿과 서류철을 안고 들어온다.
선반 사이를 지나며 수장품 번호를 확인한다.
```

**소해** 수장번호 91-0428… 91-0429… (멈춘다) …0430.

```
구석. 천으로 덮인 캔버스 하나.
다른 것들과 달리, 노끈으로 묶이고 봉인 딱지가 붙어 있다.
```

**소해** (서류철을 넘기며) 91-0430. 작가명, 서인화. 제목… 〈푸른 여인〉.
(사이) 상태: 봉인. 비고… (읽다가 멈춘다) "전시 불가. 사유 — "

```
사유 칸이 비어 있다.
소해, 손전등으로 딱지를 비춘다. 삼십 년 묵은 먼지가 빛 속에 떠오른다.
서류철 뒤편에서 낡은 카세트테이프가 툭, 떨어진다.
라벨에 흐린 글씨: 「기자회견. 1991. 4.」
소해, 잠시 망설이다 낡은 재생기에 테이프를 넣는다.

지직 — 플래시 터지는 소리. 웅성거림.
그리고 늙은 여자의 목소리. 낮고, 이상하리만큼 고요하다.
```

**목소리(인화)** …몇 번을 물으셔도 대답은 같아요.
이건, 내 그림이 아닙니다.

```
웅성거림이 커진다. "선생님!" "한 말씀만요!" 플래시. 플래시.
소해, 천천히 봉인된 캔버스로 손을 뻗는다.
손끝이 노끈에 닿는 순간 —

무대 가득, 새소리.
따뜻한 빛이 어둠을 밀어낸다.
소해는 빛 바깥으로 물러나 어둠 속에 남는다.
— 과거가 시작된다.
```

## 1장 — 색채의 낙원

```
1991년 봄. 인화의 화실. 아침나절.
빈 액자들이 사방에 걸려 있고, 이젤 위에도 빈 캔버스 하나.
창으로 봄빛. 라디오에서 흐르는 옛 가요.
새장에서 — 새소리가 요란하다. 아침부터 성화다.
```

**인화** (물감을 개다 말고) 알았다, 알았어. 성화다, 성화.
(모이를 집다가, 새장 앞에서 멈칫) ……너 살쪘다?
(모이를 도로 반 덜어낸다) 반만 먹어. 화가 집 새가 뚱뚱하면 남들이 흉봐. 그림은 안 팔리는데 새만 살쪘다고.

```
대문 쪽에서 쿵쿵. 대답도 듣기 전에 —
```

**백규(소리)** 죽었나 살았나 보러 왔다!

**인화** (돌아보지도 않고) 죽었으면 곡을 하고 가지 그래.

**백규** (들어서며) 곡값이 비싸. 요즘 곡쟁이가 없어서.

```
백규, 양손 가득 — 막걸리 한 통, 신문지로 싼 참기름병.
마당을 질러 오다가, 화단 앞에서 잠깐 멈춘다.
```

**백규** ……올해도 폈네.

**인화** (화실 안에서, 여전히 돌아보지 않고) 어머니가 심은 건 안 죽어.

**백규** 꽃이 주인을 닮아야 할 텐데 말이야. (들어서서, 막걸리를 흔들며) 자, 개시하자. 어제 큰 거 하나 나갔다.

**인화** 아침부터 무슨 술이야.

**백규** 아침이 아니라 개시라니까. 어제 일본서 손님이 왔는데 말이야, 우리 가게서 세 시간을 안 가. 세 시간을! 내가 값을 세 번 올렸는데 세 번 다 "하이, 하이" — 그림값이란 게 뭐야? 부르는 놈 심장 값이야.

**인화** (물감을 개며) 그래서 얼마에 팔았는데.

**백규** ……그건 장부에 있고. (술을 따르며) 하여간 컸어. 커.

```
백규, 잔을 들고 빈 액자들 쪽으로 간다. 한 액자 앞에 잔을 쓱 내민다.
```

**백규** 느이들도 한 잔 해라. 느이 언니가 팔렸다.

**인화** (질색) 얘들은 술 못 해. 물만 마셔.

**백규** (잔을 거두며, 진지하게) ……하긴. 화가 집 딸들이 술 배우면 못써.

```
저 혼자 마신다. 캬 —
그러다, 새장 쪽을 본다.
```

**백규** ……저놈 아직 있어?

**인화** 있지.

**백규** 그림 다 그렸잖아. 재작년에.

**인화** 다 그렸지.

**백규** (한숨) 그러니까 왜 못 보내냐고.

**인화** 보내긴 어딜 보내. 모델인데.

**백규** 모델 노릇 끝났으면 월급을 끊어야지, 사람이. 저놈 모이값이 자네 물감값이야.

**인화** (모이를 주며) 자네 그 염소 얘기 또 하려고 그러지.

**백규** (기다렸다는 듯 벌떡) 염소를! 마당에다! 뿔을 그린다고!

**인화** 하지 마.

**백규** 그놈이 내 구두를 먹었어. 새 구두를. (손가락 두 개를 펴 보인다) 이만큼 남기고.

**인화** 그 구두 자네가 삼 년 신은 거야.

**백규** 삼 년을 신었어도 내 구두지! 나는 이 얘길 사십 년 할 거야. 죽을 때까지 할 거야.

**인화** (웃으며) 하세요, 하세요.

```
백규, 흡족하게 한 잔 더 마신다.
참기름병을 내려놓는다.
```

**백규** 이건 시골서 올라온 거다. 진짜배기야.

**인화** 자네가 진짜라고 하면 어째 다 가짜 같단 말이지.

**백규** 화랑 주인한테 그게 할 소리야? 나는 말이야, 진짜만 판다. 사십 년을.
(이젤 쪽을 기웃거리며) …새로 하는 거야? 어디 봐.

**인화** (몸으로 슬쩍 가리며) 아직 안 돼.

**백규** 아직도 안 돼? 지난달에도 아직이었어.

**인화** 얘가 아직 대답을 안 했어.

**백규** (한숨) 또 그 소리. 그림이 무슨 대답을 해.

**인화** 대답을 해. 다 되면, 어느 날 아침에 얘가 먼저 날 봐. 내가 얘를 보는 게 아니라 얘가 날 봐. 그때 서명하는 거야.
(붓을 내려놓으며) 대답도 안 한 그림에 이름을 넣으면, 그건 그림이 아니라 거짓말이지.

**백규** …그 성미에 사십 년을 어떻게 팔아먹고 살았는지, 원.
(둘러보며) 근데 오늘은 뭐 좋은 일 있나? 라디오도 틀고.

**인화** (웃음을 참으며) 도윤이가 온댔어.

**백규** 도윤이? 그 논문 쓰던 청년? 아직도 자네 꽁무니를 쫓아다녀?

**인화** 이제 청년 아니야. 미술관 학예실장님이셔.

**백규** (휘파람) 출세했네. 내가 저럴 줄 알았어. 논문 쓴답시고 우리 가게서 도록을 석 달을 빌려 가더니. 그때 안 빌려줬어야 했는데, 사람을.

**인화** 빌려주고 자랑은 자네가 십 년을 했지.

**백규** 하기야 자네 그림으로 논문을 썼으니 자네가 팔자를 고쳐준 셈인가.

**인화** 내가 아니라 그림이 고쳐줬지.

```
문 두드리는 소리. 이번엔 공손하게, 세 번.
정도윤, 꽃다발과 서류가방을 들고 들어온다. 양복이 몸에 아직 설다.
```

**도윤** 선생님.

**인화** (환해지며) 어서 와요.

**도윤** (허리 숙여 인사하고, 백규를 보고 또 인사) 사장님도 계셨네요.

**백규** 실장님 되셨다고? 이제 자네가 나보다 높은 사람이야. 인사는 내가 해야지.

**도윤** (질색하며) 그런 말씀 마세요. 저는 아직도 선생님 화실 문턱이 세상에서 제일 높습니다.

**인화** 능청은. 앉아요. 차 줄게.

**백규** (막걸리 통을 들며) 실장님도 한 잔 해야지. 계약인데.

**도윤** 아, 저는 근무 중이라 —

**백규** 한 잔은 인사고, 두 잔부터가 술이야. 자넨 인사만 해.

**도윤** (잔을 받으며, 인화 눈치를 보고) ……인사만 하겠습니다.

```
인화, 차를 준비한다. 도윤, 화실을 둘러본다.
빈 액자들 앞에서 하나하나 걸음을 멈춘다. 오래 알던 얼굴들을 만나듯.
```

**도윤** (한 액자 앞에서) …〈달을 삼킨 새〉. 실물은 처음 봅니다.
논문 쓸 때 도판으로만 백 번은 봤는데.
(사이) 이상하죠. 도판으로 볼 땐 새가 달을 삼키는 줄 알았어요. 실물을 보니까… 새가 달을 뱉어주고 있네요. 세상이 어두울까 봐.

**인화** (찻잔을 내리다 멈추고, 도윤을 본다)
…그걸 보네.

**도윤** 네?

**인화** 사십 년 동안 아무도 그 소리를 안 했어. 평론가들도, 기자들도. 다들 삼킨다고만 했지.
(찻잔을 건네며) 뱉어주는 거 맞아. 그 새는.

**백규** (헛기침) 거 참, 나는 사십 년을 봐도 새는 새고 달은 달이더구먼.

**인화** 그러니까 자네는 사십 년째 화상(畵商)이지.

**백규** 사십 년째 자네 그림값 올려준 게 누군데!

```
웃음. 차를 마신다. 오후의 빛이 조금 기운다.
도윤, 찻잔을 내려놓고 서류가방을 연다. 조심스럽다.
```

**도윤** 선생님. 실은… 오늘은 부탁이 있어서 왔습니다.

**인화** 부탁?

**도윤** 미술관에서 올봄부터 새 사업을 합니다. '찾아가는 미술관'이라고…
수장고에 잠들어 있는 작품들을 꺼내서, 전국을 도는 겁니다. 미술관 문턱을 못 넘는 사람들한테 그림이 직접 찾아가는 거죠. 광부들 사택에도 가고, 섬마을 분교에도 가고.

**백규** (끼어들며) 그림이 순회공연을 하는구먼.

**도윤** 그 첫 전시에… 선생님 작품을 걸고 싶습니다.
(사이) 제일 앞에, 제일 잘 보이는 자리에.

```
사이.
인화, 찻잔을 두 손으로 감싼 채 말이 없다.
```

**인화** …섬마을 분교라고 했나.

**도윤** 네. 남해 쪽부터 돕니다.

**인화** (혼잣말처럼) 그림은 부잣집 응접실보다 그런 데 걸리고 싶어 하지.
(빈 액자들 쪽을 슬쩍 보며, 낮게) ……그렇지? 느이도 그러니?
(사이. 대답을 들은 사람처럼, 도윤에게) 들었죠? 내 그림이 뭘 하겠다는데 내가 왜 말려.

**도윤** (환해지며) 감사합니다, 선생님!

**인화** 나한테 말고 그림들한테 해요, 인사는.

**도윤** (일어나 빈 액자들을 향해 넙죽 허리를 숙인다) 잘 부탁드립니다!

```
웃음이 터진다.
백규가 빈 막걸리 통을 흔들어 보고 "축하주가 동났네!" 하며 참기름병을 집어 들고,
인화가 "그건 참기름이야 이 사람아" 하고.
소란한 온기. 라디오의 옛 가요가 조금 커진다.

이윽고 손님들이 돌아가고 —
화실에 인화 혼자 남는다.
저녁 빛. 인화, 이젤 앞에 다시 앉는다.
```

**인화** (캔버스 속 누군가에게) …들었지?
너희 언니들이 여행을 간단다. 남쪽 바다로.

```
사이. 저녁 빛이 캔버스에 고인다.
인화, 붓끝으로 허공의 한 점을 짚는다.
```

**인화** …그렇게 보지 마라.
네 눈이 너무 맑아서 탈이야. 눈이 맑으면 세상이 다 비쳐. 세상이 다 비치면… 슬퍼지고.
(사이) 그래서 너한테 꽃을 주는 거야. 왼쪽 귀 위에, 흰 꽃 하나.
슬픈 눈을 한 애들한테는 꽃을 꽂아줘야 해. 그래야 사람들이 네 슬픔을 훔쳐보지 않고… 꽃을 보지.
(붓을 들다가, 문득)
부럽니? 너도 얼른 대답을 해. 그럼 너도…

```
그때.
어디선가 — 아주 멀리서 — 여자의 낮은 허밍이 들린다.
낯선 노래. 인화의 라디오에서 나오는 것이 아니다.

인화, 붓을 든 채 천천히 고개를 든다.
빈 액자들 사이, 어둠이 고인 자리를 오래 바라본다.
```

**인화** ……누구니?

```
허밍, 뚝 끊긴다.
암전.

— 1장 끝 —
```

### 1장 재증축 (2026-08-19, 하작가님 피드백 반영 — 지적 2·3)
- **염소 비트 신설**: 하작가님 지적 ②"백규의 캐릭터적으로 재미있는 부분을 더" 직접 이행. 백규 말투 사양 2번(숫자의 자서전: "사십 년 할 거야")·4번(능청) 사용. 허풍이 아니라 **원한의 되풀이** — 새 형태의 웃음이라 허풍 총량과 별개
- **새장의 내력 심기**: 하작가님 지적 ③의 모델 화가 일화(닭을 사와 키우다 처치 곤란·뱀을 키움)에서 **성질만** 추출 — "그리려고 직접 키운다 / 끝나도 못 보낸다". 실존 지표(닭·뱀·대학)는 전부 버리고 우리 극의 새·염소로 치환 (정본 7항 허구화 원칙 유지)
- **효과**: 지금까지 이유 없이 놓여 있던 **빈 새장에 근거가 생김.** "화가 집 새가 뚱뚱하면 흉봐"가 십 년째 못 보낸 모델의 농담이 되고, 3장 "자라"(새장에 보 덮기)와 4장 이후 새소리의 유무가 무거워진다
- ⚠️ 퇴고 과제: 6장(절필)에서 새를 한 번 회수할지 — 현재 6장에 새 언급 0. 낭독으로 판정

### 1장 증축 (2026-08-16, 배우님 지시 "농담으로 활기차게 시작")
- **오프닝 교체**: 조용한 그림 대화 → 새 소동("너 살쪘다?") + 백규의 왁자한 등장. 코미디 오프닝 = 감동원칙 1 + 볼거리 원칙
- **꽃 대화는 저녁 코다로 이동** — 오프닝은 활기, 코다는 서정. 하루의 낙차
- **변주 AS 사용**: 화단 "올해도 폈네 / 어머니가 심은 건 안 죽어" — 4장 AB("어머니 관에 넣었던 꽃")의 조건 ① 완성
- **막걸리 비트 신설**: 그림들에게 술 권하는 백규 / "얘들은 술 못 해. 물만 마셔" — 그림=딸 세계관을 코미디로 소개
- **허풍 1회**: 일본 손님 무용담 ("그건 장부에 있고" 자가 부식) — 허풍 총량 1장 몫 사용
- 도윤 잔 비트("한 잔은 인사고 두 잔부터가 술이야") + 끝 개그 승격(빈 통 → 참기름)
- 증축 후 분량: 1장 낭독 약 7.5분 → 무대 약 12~13분 (프롤로그 포함 도입부 ~16분)

- **문체:** 사실주의 바탕 + 그림에게 말 걸 때만 시적으로 전환 (레드의 예술론 대사 + 차범석의 생활 말맛 배합)
- **심은 복선:**
  - "대답한 그림에만 서명한다" → 5장 서명 거부의 씨앗
  - "슬픈 눈에 꽃을 꽂는다" → 화가의 존재 선언이자 제목 후보였던 정서
  - 도윤의 "뱉어주는 새" → 그가 인화를 가장 깊이 이해하는 사람임을 증명 → 3장의 배신이 가장 아프도록
  - 마지막 허밍 → 그림 속 여인(2장에서 도착할 〈푸른 여인〉)의 예고
- **프롤로그 장치:** 사유 칸이 비어 있는 봉인 딱지 = 극 전체의 질문. 테이프 목소리로 결말을 먼저 던지고 시작 (관객은 '어떻게'를 보러 가는 구조)
- **1인 2역 운영:** 프롤로그의 소해는 어둠 속에 남아 1장을 지켜봐도 좋음 (연출 선택지)
