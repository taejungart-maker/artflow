```
인화, 낙관을 서랍에 도로 넣는다. 서랍을 닫는다 — 조용히, 오래 닫는다.
여인, 촛불 빛의 가장자리로 물러난다.
물러나며 — 낮게, 허밍.
1장의 그 노래다.
```

**인화** (눈을 감고 듣는다) ……가니.

**여인** (허밍을 멈추고) ……비 그치면요.

```
여인, 어둠 속으로.
허밍만 남는다. 잦아든다.

촛불 빛 속, 인화 혼자.
붓을 든다. 촛불에 비춰 본다. 오래 본다.
— 붓을, 수건에 만다. 가지런히. 장례처럼은 하지 않는다. 그냥, 저녁마다 하던 대로.

빗소리.
2021년의 빛이 스며든다 — 수장고의 손전등 빛.
소해, 낡은 화첩을 넘기고 있다.
1991의 인화, 어느새 곁에 앉아 같은 페이지를 보고 있다.
```

**인화** 그 봄엔 목련을 못 그렸어.

**소해** (놀라지 않는다) ……왜요.

**인화** 마당에 피기도 전에 다 졌거든. 비가 사흘을 왔어.

**소해** (페이지를 넘긴다. 빈 장이다) ……그래서 여기가 비었구나.

## 에필로그 — 빈 액자

```
수장고. 손전등 빛.
소해, 혼자다. 무릎 위의 낡은 화첩 — 빈 장이 펼쳐져 있다.
가만히, 덮는다.

봉인된 캔버스 앞에 선다.
서류철을 연다.

```

```

```

```
천이 흘러내린다.

빈 액자.
소해, 그림을 본다. 오래 본다.
그림도, 그녀를 볼 것이다 — 같은 얼굴이니까.
```

**소해** (그림에서 눈을 떼지 않은 채) ……선생님.

```
수장고 한켠에 — 1991년의 빛이 한 조각 켜진다.
마당 수돗가. 인화, 붓을 씻고 있다.
```

**인화** (씻으며) ……오늘 치 붓 씻는 거.

```
소해, 잠자코 듣는다.
```

**인화** (붓을 털며) 내일 또 씻고.

**무전기(소리)** 윤 선생님, 점검 다 끝나셨어요? 오늘까지 목록 넘겨야 하는데, 91-0430 하나만 비었어요.
