## 5장 — 붓

```
(플래시 소리가 — 빗소리에 씻겨 나간다.
1991년 7월. 장마. 성북동 마당.
처마에서 물 떨어지는 소리. 세상 소리를 비가 지운다.
비가 잠시 갠 오후. 백규, 우산을 털며 들어온다.)
```

**백규** 마당 다 젖었구먼.
**인화** (마루에 앉아, 마당을 보며) 꽃은 좋아해.

**인화** 비 그치면.

```
(백규, 마루 끝에 앉는다. 우산을 접는다. 접었다가, 괜히 다시 편다.)
```

**백규** 인사동은 조용해. 요즘은 자네 얘기 안 하더라.
**인화** ……
**백규** 수돗물 얘기도 안 해. 다들 잘만 마셔. (사이) 세상 참…… 빨라.
**인화** 빠르지. (마당의 화단을 보며) 꽃만 제 속도로 살아.

```
(사이. 빗소리.)
```

**백규** 붓은…… 요즘 드나.
**인화** (대답 대신, 마당을 본다.)
**백규** ……그래. 비 오는데 무슨. (일어선다) 간다. 뭐 먹고 싶은 거 있으면 기별해. 내 세상없어도 사 온다.
**인화** ……백규야.
**백규** 왜.
**인화** (사이) ……고맙다.
**백규** (우산을 쓰며, 돌아보지 않고) 별소리를 다 한다. 비나 새지 마라, 이 집.

```
(백규, 나간다.
빗소리가 다시 굵어진다.
저녁. 화실.
인화, 막내 캔버스 앞에 앉는다. 붓을 든다.
들고만 있다.

그때 — 전등이 깜빡, 나간다. 정전.
빗소리 속의 어둠.
인화, 익숙하게 초를 찾아 켠다.
촛불 하나의 빛.

그 빛 언저리에 — 여인이 서 있다.
푸른 옷. 귀 위에 흰 꽃.
인화, 놀라지 않는다.)
```

**여인** ……왜 요즘, 안 그려요.
**인화** (붓을 든 채) ……그 여자를 봤어. 너랑 똑같이 생긴 여자.
**여인** ……
**인화** 똑같더라. 눈매도, 꽃도, 앉음새도. (사이) 근데 눈에, 내가 안 넣은 슬픔이 있어.
나는 슬픔을 그렇게 안 그려.
나는 슬픔에도 꽃을 꽂아.
**여인** (제 귀 위의 꽃에, 가만히 손을 올린다.)
**인화** ……그래. 그거.

```
(사이. 빗소리.)
```

**여인** 사람들이 그 여자를 나라고 해요.
**인화** ……그러더라.
**여인** 어머니까지 헷갈리면, 나는 어떡해요.
**인화** (처음으로 여인을 똑바로 본다) 내가 왜 헷갈려.
**여인** ……밤에. 물으셨잖아요. 내가 그렸나, 하고.

```
(긴 사이.
인화, 붓을 내려놓는다.)
```

**인화** ……무서워서 그랬다.
세상이 다 한목소리로 말하면, 사람이 제 눈을 의심하게 돼.
(사이) 근데 너를 보니 알겠다. 나는 안 헷갈려. 한 번도 안 헷갈렸어.

```
(인화, 서랍에서 낙관을 꺼낸다. 인주도.
막내 캔버스 앞에 놓는다.
한참 본다.
— 찍지 않는다.)
```

**여인** ……안 찍어요?
**인화** 낙관 없는 그림은 못 팔아. 못 걸고, 못 내보내. (사이) 그러라고 안 찍는 거야.
**여인** ……
**인화** (막내에게) 너는 안 내보낼란다. 밖이 요즘…… 사납다.
도장 없으면 아무도 너를 감정 못 해. 진짜라고도, 가짜라고도.
(사이) 너는 그냥…… 내 딸로 살아.

```
(인화, 낙관을 서랍에 도로 넣는다. 서랍을 닫는다 — 조용히, 오래 닫는다.
여인, 촛불 빛의 가장자리로 물러난다.
물러나며 — 낮게, 허밍.
1장의 그 노래다.)
```

**인화** (눈을 감고 듣는다) ……가니.
**여인** (허밍을 멈추고) ……비 그치면요.

```

붓을 든다. 촛불에 비춰 본다. 오래 본다.
— 붓을, 수건에 만다. 가지런히. 장례처럼은 하지 않는다. 그냥, 저녁마다 하던 대로.

빗소리.
2021년의 빛이 스며든다 — 수장고의 손전등 빛.
소해, 낡은 화첩을 넘기고 있다.
```

**인화** 마당에 피기도 전에 다 졌거든. 비가 사흘을 왔어.
**소해** (페이지를 넘긴다. 빈 장이다) ……그래서 여기가 비었구나.

## 작가 노트 (5장)

- **절필 선언의 담백 번역:** 초기 설계의 "너희가 진짜라 부르는 세상에 나는 서명하지 않는다"(관념·선언)를 **낙관 비트**로 전면 교체 — "낙관 없는 그림은 못 팔아. 그러라고 안 찍는 거야. / 너는 그냥 내 딸로 살아." 서명 거부가 어미의 보호로. 실물(도장·인주)이 말하고, 관념어 0
- **여인 = 젊은 인화 겹** (연출 장치 5): 명찰 없음. "어머니까지 헷갈리면, 나는 어떡해요" — 3장 자기 의심의 밤을 그림 쪽에서 되물음. 위작 대면 7단계의 ⑥⑦이 여기서 회수
- **"말로 그리는 그림" 확정 대사 사용** (연출 장치 3): "나는 슬픔에도 꽃을 꽂아" — 극 전체에서 가장 시적인 문장 하나를 이 자리에만 허용 (시는 희소해서 시다)
- **백규 비트 (AU 사용):** "요즘은 자네 얘기 안 하더라 / 수돗물 얘기도 안 해" — 세상의 잔인한 회복. "고맙다"에 "별소리를 다 한다" — 두 사람의 40년을 두 마디로
- **AC 겹장면 = 에필로그로 가는 다리:** 1991의 촛불이 2021의 손전등으로 — 시간이 처음으로 한 무대에 겹침 (놀라지 않기)
- **관객 선물:** 여인의 등장 (그림이 걸어나오는 순간 — 이 극의 가장 아름다운 무대 그림) + 낙관을 찍지 않는 손
- 정전→촛불: 장마 정전이 단일 촛불 조명의 생활 근거 (오감의 현실주의 — 조명 디자인에 이유가 있음)
- ⚠️ 퇴고 과제: 여인의 대사량 (현재 5마디 — '놀라지 않기' 문법상 더 줄일지 낭독으로 판정)
