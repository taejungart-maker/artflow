## 1. 두 작품의 좌표

| | 《리어》 | 《사소한 것들》 |
|---|---------|---------------|
| 세대 | 기성 (배우 중심 회고극) | 신진 (서울연극제, 앙상블 직장극) |
| 문체 | **시적 리얼리즘** — 기억·독백·사물시학 | **하이퍼리얼리즘** — 직장 구어 완전 채록 수준 |
| 구조 | 노배우의 인생 ↔ 리어왕 겹침 (메타연극) | 50만원 수당 오지급 → 감사 → 신고 → 조리돌림 |
| 언어 단위 | 긴 서사 독백 + 단타 대화 교대 | 짧은 릴레이 발화의 연쇄 (앙상블 다중 화자) |
| 클라이맥스 처리 | 문장의 파편화·반복 ("내가 질문해요 / 나야 / 내가") | 관료 언어의 냉정함 ("신고감이 되지 않습니다") |
| 결말 톤 | 실존적 여운 (To be or not to be) | **조용한 다짐** — "누가 한 사람은 얘기해야죠… 멈칫할 수 있다니까요" |

## 2. 《리어》의 화법 (기성 시적 리얼리즘) — 6특징

1. **비완결 문장의 흐름** — 군말(아니, 뭐, 그냥, 막)이 살. 완성문 회피
2. **단타 연쇄 ↔ 긴 독백 교대** 리듬
3. **시는 사물에서** — 봉고차·낡은 담요·굳은 눈망울·"새벽 5시 36분" (구체성=진정성)
4. **클라이맥스 = 반복+파편화** (고함 아님)
5. **문어 인용의 충돌** — 셰익스피어 원문 톤이 구어 사이에 꽂힐 때의 서늘함
6. **능청 유머** 숨구멍 ("곡값이 비싸")

## 3. 《사소한 것들》의 화법 (신진 하이퍼리얼) — 6특징

1. **직장 구어의 완전 채록** — 호칭 체계(쌤/실장님/과장님/학장님)가 곧 권력 지도. 존댓말 층위가 인물 관계를 그림
2. **앙상블 릴레이 발화** — 짧은 대사가 여러 입으로 튀며 굴러감. 잡담·아재개그·별명 놀이("얼펑" 퀴즈, 파 키우기)로 일상의 공기부터 구축 → 그 공기가 무너질 때 공포
3. **관료 언어 자체가 폭력** ⭐ — "오지급", "업무 배제", "재발 방지", "사실관계 확인", "일방적 가해로 규정하기에는", **"신고감이 되지 않습니다"** — 제도의 언어가 사람을 지우는 과정을 언어 그대로 무대화
4. **감정 폭발도 생활어로** — "범죄 행위라고!" / "더 해! 더!" 짧고 즉물적. 웅변 없음
5. **숫자의 리얼리즘** — "16만원 곱하기 3, 48만원, 세금 떼면…" 정확한 계산이 진정성과 씁쓸한 유머를 동시에
6. **조용한 결말** — 카타르시스 대신 일상 복귀 + 낮은 목소리의 다짐. 관객이 대신 뜨거워짐

## 4. 두 작품의 공통분모 = 지금 대학로의 공통 문법

1. **구체성 = 진정성** (정확한 숫자·사물·시각)
2. **제도의 언어 vs 개인의 언어 충돌**이 극의 엔진
3. **클라이맥스의 절제** — 데시벨이 아니라 파편화·침묵·냉정한 문장으로
4. **유머는 필수 숨구멍** — 무거울수록
5. **비완결 구어체** — "쓰여진 말"은 즉시 들통남

## 5. 💡 주제적 발견 — 두 극 모두 《감정》과 같은 과(科)

- 《리어》: 배우가 "나는 진짜 리어였다"를 세상에 증명 못 함 → **존재 증명의 극**
- 《사소한 것들》: 개인의 신고가 제도 언어에 의해 "신고감이 되지 않는다"로 지워짐 → **자백마저 버려지다(우리 4장)의 직장 버전**
- = 배우님이 고른 두 편이 모두 "개인 vs 제도" — 《감정》의 형제 작품들. 지금 대학로가 이 주제에 반응하고 있다는 방증 (시의성 확인)

## 6. ✍️ 《감정》 적용 지침

| 적용처 | 지침 | 출처 |
|--------|------|------|
| 전체 대사 | 완성문 비율 낮추기, 군말 허용, 말 겹침 | 공통 |
| 인화의 독백 | 사물시학 유지 ("왼쪽 귀 위에 흰 꽃 하나") + 긴 독백·단타 교대 | 리어 |
| **정도윤의 언어 변화** ⭐ | 1장 사물시학("달을 뱉어주는 새") → 3~4장 관료어("사실관계 확인", "규정상") — **한 인물의 화법 이행 = 배신의 언어적 형상화** | 두 작품 합성 |
| 3장 감정서·기자 코러스 | 실제 감사·감정 용어를 정확히 차용 (가짜 관료어는 티 남) | 사소한 것들 |
| 3장 자기 의심의 밤 | 반복+파편화: "내가… 그렸나. 내가 그렸지. 내가… 그렸던가." | 리어 |
| 4장 절정 | 제도의 최종 문장은 냉정하게 — "본 위원회는 재감정의 사유가 없다고 판단합니다" | 사소한 것들 |
| 5장 서명 거부 | 웅변 금지. 낮고 조용하게 — 사소한 것들의 결말 톤 | 사소한 것들 |
| 유머 배치 | 백규 능청(리어형) + 화실의 일상 공기(사소한 것들형)를 1장에 충분히 | 공통 |
