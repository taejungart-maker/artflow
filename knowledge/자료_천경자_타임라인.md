## 3. 미인도 사건 일지

| 시점 | 사건 |
|------|------|
| 1977 | 〈미인도〉 제작 연도로 표기된 작품 (26×29cm 소품) |
| 1980 | 국립현대미술관 소장 (압류 재산 이관 경위 — 검찰 수사에서 "1980년 소장" 확인) |
| 1990.4 | **'움직이는 미술관' 순회전**을 통해 작품 존재가 처음 외부에 알려짐 |
| 1991.4.2 | **위작 논란 시작** — 작가가 "내 그림이 아니다" 주장. 작가 대 국립현대미술관 구도 형성 |
| 1991.4 | 국립현대미술관 의뢰로 **한국화랑협회 감정위원회** 감정 — 1차 "적어도 가짜는 아니다", 2차 "진품" 결론 |
| 1991 | 작가, "화단 풍토에 환멸을 느낀다"며 **절필 선언** → 4개월 미국 체류 |
| 1991 말~ | 귀국 후 "절필은 죽음과도 같다"는 깨달음으로 **다시 붓을 잡음** → 1995 호암 회고전으로 이어짐 |
| 1999 | 고서화 위조로 구속된 **위조범 권춘식**, 검찰 조사에서 "화랑 주인 부탁으로 달력 그림들을 섞어 미인도를 그렸다" 자백 |
| 2015.8 | 작가 타계 (10월 공표) |
| 2016 | 유족 고소로 서울중앙지검 재수사 — 권춘식 소환 진술("내가 그린 위작"), 프랑스 뤼미에르 테크놀로지 감정 참여 논란 |
| 2016.12 | 검찰 결론: **"진품"** — 근거 ①국과수·카이스트 안료 분석 = 작가 상용 안료와 동일 ②권춘식 위조 주장 시점(1984)과 미술관 소장 시점(1980) 불일치 |
| ~현재 | 감정서 공개 소송 등 법적 다툼 지속 (2025년에도 법원 "감정서 공개" 판결 보도) — **사회적으로는 여전히 미종결** |

### 사건의 뼈대 (한 줄 요약)
> 작가는 죽을 때까지 "내 그림이 아니다"라 했고, 제도는 두 번(1991 화랑협회, 2016 검찰) "진품"이라 답했으며, 위조범의 자백은 시점 불일치로 기각됐다 — **진실은 법적으로 '진품', 사회적으로 미궁.**

## 4. 《감정》 접속 포인트 (허구화 대조표)

| 실제 | 《감정》 (허구화) |
|------|----------------|
| 1990.4 순회전으로 존재 공개 → 1991.4 논란 | '찾아가는 미술관' 준비 중 도판에서 발견 (2장) — 시간 압축 |
| 화랑협회 감정 "진품" | 가상 감정위원회 (3장) — 특정 단체 지칭 없음 |
| 절필 선언 → 복귀 | 인화는 절필로 닫음 (5장 "빈 캔버스 = 마지막 작품") — **실제와 결말이 다름을 명확히** (허구임의 증거) |
| 위조범 자백(1999) 시점 불일치로 기각 | 무영의 자백 즉시 기각 (4장) — 시간 압축, "실력이 안 된다" |
| 뉴욕 이주·타계, 사후에야 알려진 죽음 | 인화의 30년 침묵 (프롤로그·에필로그의 수장고) |
| 진품/위작 법적·사회적 미종결 | 극이 진위를 판정하지 않음 — 관객=배심원 |

- 주의: 절필 후 복귀·호암 회고전·시립미술관 기증 등 **실제 후반부 생애는 우리 극과 완전히 다름** — 인화≠실존 작가의 핵심 근거이므로 프로그램북 명기 문구 유지
- ⚠️ 극 중 어떤 대사도 실제 발언의 직접 인용이 아닐 것 (정본 7장 ⑤)
