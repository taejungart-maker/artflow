## 0. 왜 이 작품인가 — 《감정》과의 혈연 관계

| 항목 | 다우트 | 《감정》 |
|------|--------|---------|
| 배우 | **4인** | 5인 |
| 무대 | 소극장, 공간 3개 | 소극장, 공간 3개 |
| 러닝타임 | ~90분, 인터미션 없음 | ~90분 설계 |
| 핵심 질문 | 진실은 무엇인가 — **끝내 안 알려줌** | 그림의 진위 — **끝내 판정 안 함** |
| 주제 | 확신의 폭력, 개인 vs 제도(교회) | 제도의 확신이 개인을 지움 |
| 실화 관계 | 가톨릭 스캔들 시대 배경이나 부제가 "우화" — **허구 선언** | "실화 모티프 창작극" — 동일 전략 |

→ 우리가 가려는 길을 **먼저 완주하고 퓰리처까지 받은 작품.** 훔칠 자격이 충분하다.

## 1. 작품 개요 (3분 요약)

1964년 브롱크스 성 니콜라스 가톨릭 학교. 교장 **알로이시스 수녀**(규율의 화신)는 **플린 신부**(개혁적·친근한 인기인)가 학교 유일의 흑인 학생에게 부적절한 짓을 했다고 확신한다. 증거는 없다 — 어린 **제임스 수녀**가 본 애매한 정황뿐. 알로이시스는 확신만으로 전쟁을 시작하고, 소년의 어머니 **뮬러 부인**마저 뜻밖의 말을 하는데… 플린은 끝내 전보(사실상 승진)로 떠나고, 철의 확신이던 알로이시스는 마지막에 무너진다 — *"나는 의심이 들어. 너무나 의심이 들어!"*

**관객은 끝까지 플린이 유죄인지 모른다.** 이것이 이 극의 전부다.

## 2. 구조 해부 — 9장, 인터미션 없음

### 장 지도

| 장 | 공간 | 내용 | 기능 |
|:--:|------|------|------|
| 1 | 설교단 | 플린의 설교 "확신이 없을 때 어떻게 하는가?" — 난파 선원 우화 | **주제 선언 + 관객 직접 호명** |
| 2 | 교장실 | 알로이시스×제임스 — 볼펜 혐오, '프로스티' 이교 판정 등 | **유머로 인물 정 들이기** + 의심의 씨앗 |
| 3 | 체육관 | 플린의 농구·위생 강의 ("손톱은 좀 길어도 돼") | 플린의 매력 + 이중 해석 가능한 디테일 |
| 4 | 정원 | 제임스가 목격 정황 보고 (술 냄새) | 방아쇠 |
| 5 | 교장실 | **1차 대결** — 플린 해명(제단 포도주), 표면상 종결. 플린이 교장 의자에 앉는 순간! | 위계 과시 + 가짜 해소 |
| 6 | 설교단 | 2차 설교 — **베개 깃털 우화** (소문은 깃털처럼 회수 불가) | 반격 + 주제 변주 |
| 7 | 정원 | 플린×제임스 — 그녀의 신뢰를 얻어냄 | 중간자의 동요 |
| 8 | 교장실 | **뮬러 부인 장면** (대반전) + **2차 대결** — 알로이시스의 거짓 승부수 → 플린 전출 요청 | 극의 심장 |
| 9 | 정원 | 코다 — "그는 승진했어." 그리고 마지막 붕괴 | 제도의 승리 + 확신의 패배 |

### 훔칠 구조 기법 5

1. **설교 = 1인 코러스** — 배우 1명의 연설이 막간·주제 변주·관객 호명을 전부 수행. 비용 0. → 우리 '감정서 낭독'과 같은 계열인데, 다우트는 이걸 **가해 혐의자의 입**에 줘서 매력과 위협을 동시에 쌓음. 《감정》에서 도윤의 '브리핑' 장면에 응용 가능 — 제도의 입이 관객에게 직접 말하게 하기
2. **같은 방, 두 번의 대결** (5장·8장) — 같은 공간·같은 배치에서 판돈만 올려 반복 → "은유는 한 번, 변주는 상승" 원칙의 교과서. 관객은 지형을 아니까 긴장에만 집중
3. **뮬러 반전 (8장)** ⭐ — 피해자의 어머니가 구원자로 올 줄 알았는데 *"6월 졸업까지만 버티면 돼요"* — **구원처럼 온 것이 더 깊은 어둠.** 우리 4장 '자백마저 버려지다'와 정확히 같은 기능. 배치도 같다: 절정 직전, 관객의 도덕 나침반을 부수는 제3자
4. **마지막 5초의 역전** — 90분 쌓아온 '확신의 탑'을 마지막 한 줄로 흔들고 암전. 관객은 논쟁을 들고 극장을 나간다 → 우리 에필로그 "당신이라면, 겁니까?"와 같은 설계 사상. **답이 아니라 질문을 기념품으로**
5. **50:50 증거 배분의 기술** — 모든 정황(포도주, 손톱, 속옷, 전력)에 유죄/무죄 해석이 정확히 쌍으로 존재. 한쪽으로 1%라도 기울면 극이 죽는다. → 《감정》에서 그림의 진위 관련 정보를 낼 때마다 **반대 해석 대사를 반드시 쌍으로** 넣을 것

## 3. 유머 코드 분석 — 어디서, 왜 웃기나

### 유머의 3유형
| 유형 | 담당 | 예 | 작동 원리 |
|------|------|-----|----------|
| **권위의 진지한 부조리** | 알로이시스 | "'프로스티 더 스노우맨'은 마법을 조장하는 이교 노래", 볼펜은 필체를 타락시킨다 | 경직을 **진지하게** 밀어붙일수록 웃김. 본인은 절대 안 웃는다 |
| **순진함의 유머** | 제임스 수녀 | 역사 수업이 재밌기를 바라는 죄책감 | 착한 사람이 규율 세계에서 쩔쩔맬 때 |
| **친화의 유머** | 플린 | 농구 강의, 손톱 관리론 | 매력 구축 — 나중에 이 매력이 의심의 대상이 되면서 서늘해짐 |

### 유머 배치의 전략 (이게 핵심)
- 유머는 **1~3장에 집중** → 4장부터 급감 → 8~9장 전무. **유머가 사라지는 속도 = 극이 조여오는 속도.** 관객은 웃음이 끊긴 걸 몸으로 느끼며 불안해진다
- 기능: ①인물에게 정 들이기 (감동원칙 1의 변형 — 알로이시스를 '괴물'이 아니라 '웃긴 고집쟁이'로 먼저 만나게 함 → 마지막 붕괴가 아프다) ②설명 대사를 유머로 변환 (시대·규율 세계관을 웃기면서 전달) ③후반 낙차 확보

### 《감정》 적용
- 백규의 능청은 이미 있음 ✅. 추가로 훔칠 것: **인화에게 '진지한 고집' 유머 부여** — 예: 특정 붓 의식, 전화기 혐오, 물감 짜는 순서 같은 괴팍한 규칙을 1장에서 웃음거리로 → 3장에서 언론이 같은 고집을 "괴팍한 노인네"로 공격하는 소재로 뒤집기. **같은 특성이 웃음→무기가 되는 낙차**
- 유머 소멸 곡선 설계: 1장 풍성 → 2장 절반 → 3장 백규의 마지막 농담이 실패로 끝남(아무도 안 웃는 농담) → 4~5장 전무

## 4. 무대미술 — 아름다운 상징화의 교본

### 다우트의 설계 (토니상 무대디자인 — 존 리 비티 / 리바이벌 — 록웰 그룹)
- 원칙: **부분적 사실주의(fragmented naturalism)** — 공간 전체를 짓지 않고 의미 있는 조각만. 교장실·정원·설교단 3공간의 경제적 전환
- **창문 장치** ⭐ — 리바이벌에서 창문이 날아오르며 장면 전환, 정원 세트의 창 너머로 교장실이 보임 → 창 = **전환의 통로이자 '감시/훔쳐보기'의 시각화.** 장치 하나가 기능(전환)과 의미(주제)를 겸함
- 상징 체계 (전부 3개 이하, 전부 실용 겸용):

| 상징 | 형태 | 의미 |
|------|------|------|
| **설교단의 높이** | 플린만 높은 곳에서 말함 | 제도 권력의 수직성 — 알로이시스는 낮은 사무실에서 일대일로만 싸움 |
| **정원 벤치** | 유일한 야외·중립지대 | 규칙 밖의 대화만 진실함. 마지막 붕괴도 정원에서 |
| **바람·까마귀** | 조명·음향 | 1964년(바티칸 공의회) 변화의 바람, 불길함 — 물체 추가 없이 소리로 |

### 《감정》 무대 상징화 지침 (다우트에서 직수입 + 우리화)

1. **빈 액자 = 우리의 '창문'** ⭐⭐ — 다우트 창문 기법 직수입: 빈 금빛 액자 너머로 **다른 시공간의 인물이 보이게** 연출. 프롤로그에서 소해가 액자를 볼 때 그 너머에 1991년의 인화가 서 있고, 관객은 액자를 '통해' 과거로 들어간다 → 전환 장치이자 "그림 속을 들여다보는 우리"라는 주제의 시각화. 겹침 전환의 무대미술 버전
2. **수직성 설계** — 기자회견 단상·감정위원석은 높게(제도의 설교단), 화실은 낮고 수평하게. 인화가 제도와 싸울 땐 항상 올려다보는 구도 → 5장 절필 선언만은 **같은 높이** 또는 인화가 위 (마지막 존엄)
3. **중립지대 하나** — 다우트의 정원처럼, 《감정》에도 제도 밖 공간 하나: 화실 옥상이나 골목 계단 — 무영의 자백, 백규의 사과 같은 '진실한 말'은 전부 여기서
4. **청각 상징 2개면 충분** — 도장 찍는 소리(우리의 까마귀 = 제도의 불길함) + 라디오 옛 가요(우리의 바람 = 흘러간 시절·온기). 3장에서 라디오가 뉴스로 바뀌는 순간 = 세계가 바뀌는 순간
5. **아름다움의 경제** — 다우트의 교훈: 상징물이 적을수록 각각이 강해진다. 우리 목록 최종: **빈 액자(들) + 이젤 + 높이 차이.** 끝. 나머지는 조명(빛의 유형 지도)과 소리로

## 5. 대사 기법 (보너스 수확)

- **이중 해석 대사** — "손톱은 좀 길어도 돼, 깨끗하기만 하면" : 순수하게도 불길하게도 들림. 50:50 원칙의 문장 단위 버전 → 《감정》에서 무영의 초반 대사에 심을 것 ("선생님 붓질은… 제가 제일 잘 알아요")
- **질문으로 끝나는 연설** — 플린의 설교는 늘 관객에게 질문을 던지고 끝남 → 에필로그 "당신이라면, 겁니까?"의 족보 확인
- **제목 회수 결말** — 마지막 대사가 제목을 되돌려줌 ("I have doubts!") → 《감정》도 마지막 장면에서 '감정(鑑定/感情)' 이중의미를 한 문장으로 회수할 것. 후보: 소해의 *"감정서는 남았는데… 감정은 누가 했습니까?"* (초고 때 다듬기)

## 6. 《감정》 적용 체크리스트 (집필 시 반영)

- [ ] 그림 진위 정보는 항상 유죄/무죄 해석 **쌍으로** (50:50 원칙)
- [ ] 도윤에게 '제도의 설교' 1인 연설 장면 부여 검토 (관객 직접 호명)
- [ ] 교장실 2회 대결처럼 — 화실 공간에서 대결 2회, 판돈 상승 구조
- [ ] 인화의 '진지한 고집' 유머 1장 심기 → 3장에서 공격 소재로 반전
- [ ] 유머 소멸 곡선: 1장 풍성 → 3장 실패하는 농담 → 4장 이후 전무
- [ ] 빈 액자 = 시공간 통로 연출 (프롤로그·에필로그 수미상관)
- [ ] 수직성: 제도는 높게, 화실은 수평, 절필 선언은 같은 높이
- [ ] 중립지대 공간 1개 추가 검토 (옥상/계단)
- [ ] 청각 상징 2개: 도장 소리 / 라디오 (3장에서 가요→뉴스 전환)
- [ ] 마지막 대사에서 제목 '감정' 이중의미 회수
