## 2장 — 그림의 도착

```
1991년 4월 초. 국립근대미술관, 학예실.
스팀 배관이 쿵, 쿵, 운다. 어디선가 타자기 소리.
창으로 드는 빛이 누렇다 — 황사.
책상 위에 서류 더미, 도판 대장, 교정쇄 뭉치.
빈 액자 몇 개가 벽에 기대어 있다.

정도윤, 전화를 받고 있다.
```

**도윤** (전화에) 네, 학예실입니다. …누구시라고요?
(벌떡 일어난다) 아— 선생님! 지금 아래층이세요? 올라오시라고, 네, 네!
(전화를 끊고 허둥지둥 책상을 치우며, 소리친다) 김 주임! 손님 오십니다! 커피— 아니 차— 아니, 커피!

```
직원(배우⑤ 겸), 슬리퍼를 직직 끌고 들어와 종이컵 두 개와
믹스커피 봉지, 보온병을 놓고 나간다.
문이 열리고 — 인화와 백규. 인화, 손수건으로 눈가를 누르고 있다.
```

**백규** 하늘이 아주 누렇다 누래. 눈을 뜰 수가 있어야지.

**도윤** (달려 나가 맞으며) 선생님, 이런 날 모시고… 죄송합니다. 차를 보내드린다니까요.

**인화** (손수건을 접으며) 봄이 그렇지, 뭐.
(코를 살짝 찡그리며) …잉크 냄새. 관공서는 어디나 이 냄새야.

**도윤** (웃으며) 어제 도록 교정쇄가 나와서요. 아, 여기— 실내화로 갈아 신으시면…

```
인화, 구두를 벗고 관공서 슬리퍼로 갈아 신는다. 헐렁하다.
몇 걸음. 슬리퍼 끌리는 소리.
```

**인화** (제 발을 내려다보며) …헐렁하네.

**백규** 관공서 물건이 다 그래. 제 돈으로 안 사니까 다 크게 사는 거야.

```
소파. 도윤, 보온병 물로 믹스커피를 탄다. 스팀이 쿵, 쿵.
```

**도윤** (종이컵을 내밀며) 물은 끓인 거라 괜찮습니다. 요새 수돗물이 하도 시끄러워서, 저희도 다 끓여 먹습니다.

**백규** 대구 쪽은 아주 난리라더구먼. 강물에 페놀인가 뭔가 쏟았다고.

**도윤** 서울까지야 오겠습니까. 드셔보세요, 선생님. 믹스커피라고, 요즘 관공서는 다 이겁니다.

**인화** (한 모금. 사이) …달다.

**백규** 달지. 식기 전에 마셔.

**인화** (종이컵을 두 손으로 감싼다. 손을 녹이듯) 이런 걸 다 얻어먹고. 그 시절엔 뭘 먹고 살았나 몰라.

**백규** 시작이다, 시작이야.

**인화** 꿈 먹고. …욕은 배불리 먹고.
(사이) 그래도 마음 하나는, 늘 단단히 먹고 살았지.

**백규** 그러니 지금 이만큼 살지.

**인화** 이만큼이 어느 만큼인데?

**백규** …밥은 먹고 사는 만큼.

```
웃음. 도윤, 그 틈에 교정쇄 뭉치를 탁자에 편다. 자랑스러움을 감추지 못한다.
```

**도윤** 도록입니다. 표지 보세요. 〈달을 삼킨 새〉로 갔습니다.

**백규** (들여다보고 휘파람) 이야. …관장이 나 알아. 내 화랑에 두 번 왔어.

**인화** (교정쇄 넘기며) 한 번이었지.

**백규** …두 번째는 마음으로 왔겠지.

**도윤** 남해 분교가 오월 첫 주입니다. 배로 들어가는 건 저희 미술관 생기고 처음이에요. 위에서도 다들 이 사업만 봅니다. 제가 실장 달고 처음 벌인 일이라… 솔직히 밤에 잠이 안 옵니다.

**인화** (교정쇄를 쓰다듬으며) 잠은 자요, 도윤씨.

**도윤** (서류철에서 대장을 꺼내며) 출품작이 스물두 점입니다. 도판 전부 새로 찍었습니다. 선생님이 한 번 봐주시면… 감수 도장 하나만 받으면 인쇄 넘깁니다.

```
인화, 안경을 꺼내 쓴다. 도판 대장을 한 장, 한 장 넘긴다.
오래 못 본 얼굴들을 만나듯. 손끝이 도판 위를 천천히 지난다.
```

**인화** (한 장에서) …오랜만이다, 너.
(다음 장) 아이고, 너는 액자를 갈았구나. 잘했다, 그 옷이 낫다.
(다음 장, 백규에게) 이거 자네가 판 거지. 부산으로.

**백규** 부산 아니고 마산. 그 집 사모님이 그 그림 때문에 이혼을 안 했다잖아.

**인화** (웃고, 다음 장. 다음 장.)
오랜만이—
(인사가 입에서 죽는다.
스팀 소리만. 오래.)

**인화** ……이건 뭐지?

**도윤** (들여다보고) 아, 〈푸른 여인〉. 팔십 년작이요. 팔십삼 년에 소장했습니다. 개인 소장가한테서, 정식 절차로요.
순회전 두 번째 방에 겁니다. 조명 제일 좋은 자리예요. 여인 연작 중에서도 이 작품이—

**인화** 이건 내 그림이 아니에요.

```
사이.
스팀도 멎은 듯한 정적.
```

**도윤** (웃는다) 선생님도 참.

**백규** (들여다보며) 어디 봐. …자네 그림이구먼, 뭘.

**인화** 내 그림이 아니야.

**도윤** 선생님, 십일 년 전 작품입니다. 그 무렵 여인 연작만 수십 점이셨고… 기억이란 게—

**인화** 기억이 아니야. (자기 오른손을 들어 보인다) 손이야. 내 손이 이 획을 몰라.

**도윤** (서류를 뒤진다. 웃음은 아직 얼굴에 남아 있다) 구입 기록 있습니다. 당시 감정서도 첨부돼 있고요. 전부 절차대로—

**인화** (도판을 짚으며) 이 여자 눈 밑에 붓이 세 번 갔어. 나는 눈 밑엔 두 번만 대. 세 번 가면 슬픔이 고여서… 썩어.

```
백규와 도윤, 눈이 마주친다.
— 아주 작은, 예의 바른 균열.
```

**백규** (달래듯) 이 사람아, 도판이잖아. 인쇄가 뭉개졌겠지. 실물을 봐야 알지.

**도윤** (구원받은 듯) 그렇습니다, 실물 보시죠! 마침 포장 전입니다. (전화를 들며) 수장고죠? 구일팔공의… 〈푸른 여인〉 좀 올려주세요. 네, 지금요.
(전화를 끊고, 웃으며) 보시면 기억나실 겁니다.

**인화** (조용히) 자식을 기억으로 알아보나. 그냥 알지.

```
직원(배우⑤), 빈 액자 하나를 조심스레 들고 들어와 이젤에 세운다.
— 관객에게는, 끝내, 빈 액자다.

인화, 천천히 다가간다.
황사 낀 창광이 인화의 얼굴을 창백하게 씻는다.
오래 본다. 아무도 숨을 쉬지 않는다.
```

**도윤** (등 뒤에서, 조심스레) …선생님 맞으시죠? 왼쪽 귀 위에 흰 꽃까지. 선생님 여인들, 그대로…

**인화** (그림에서 눈을 떼지 않는다.
꽃을 가리키려다 — 손을 거둔다. 말을 삼킨다)
……아니야.
(돌아선다) 이 그림, 전시에서 내려요.

**도윤** 선생님—

**인화** 내 이름을 달고 남쪽 바다까지 가게 둘 수는 없어. 애들 보는 데까지.

**도윤** (처음으로 웃음이 사라진다) …선생님. 남해 배편이 오월 첫 주로 잡혀 있습니다. 이 도록, 선생님 도장만 받으면 오늘 인쇄에 넘어갑니다. 개막이 삼 주 남았어요.
**인화** 그러니까 인쇄 전에 알았으니 다행이지.
**도윤** (사이) ……확인은 하겠습니다. 하지만 전시는 갑니다. 삼십 년을 국가가 보관한 그림이고, 절차가 다 있었습니다. 이건 국가 소장품입니다. 제 선에서 내리고 말고 할 수 있는 물건이 아닙니다.

**인화** 방금… 물건이라고 했나?

**도윤** (아차, 하지만) …작품이요. 작품입니다.

```
사이.
인화, 도윤을 오래 본다. 처음 보는 사람처럼.
```

**백규** (수습하듯 일어나며) 자, 자. 점심때 다 됐네. 나가서 밥부터 먹자고. 응?

**도윤** (허리를 숙인다. 다시 공손하게) 제가… 알아보겠습니다. 절차를 알아보고 연락드리겠습니다.

**인화** (슬리퍼를 벗고 구두를 신는다. 또박또박, 한 짝씩)
그래요. 알아봐요.
(문 앞에서 돌아서서) 도윤씨.

**도윤** 네, 선생님.

**인화** 우리 화실에서 그랬지. 새가 달을 뱉어주고 있다고.
(사이) 그 눈으로 한 번만 다시 봐요.

```
인화와 백규, 나간다. 나가며 —
```

**인화** (백규에게, 문밖에서 목소리만) 집에 가세. 마당 목련이 아침에 첫 봉오리를 텄어. 황사만 지나면 그릴 거야.

```
문이 닫힌다.
도윤, 혼자 남는다. 빈 액자와 단둘이.
오래 바라본다. 전화기를 들었다가 — 번호를 누르다 만다.
스팀이 쿵, 쿵.
```

**도윤** (혼잣말) …맞는데. 선생님 그림 맞는데.

```
빛이 바뀌면 — 같은 날 저녁. 인화의 화실.
인화, 외투도 벗지 않은 채 막내 캔버스 앞에 앉아 있다.
붓은 들지 않는다.
```

**인화** (막내에게) 너 오늘도 말 안 하니.
(사이) 내가 뭘 잘못 그렸니. 눈이니. 입이니.
…아니면 요즘 내가 딴 데 정신이 팔려서, 너한테 소원했던 게 티가 나니.

```
그때 — 허밍.
1장의 그 노래. 이번에는 조금 가깝다. 마당 어디쯤.
인화, 이번에는 고개를 들지 않는다. 붓을 쥔 손에 힘이 들어갈 뿐.
```

**인화** ……왔구나, 너.

```
허밍, 멎는다.
암전.

— 2장 끝 —
```

## 작가 노트 (초고 메모)

- **직관 패스 (2026-08-17, 배우님 되물음 "무슨 의미일까?"):** "기억날 게 없어야 할 텐데"(부정+가정 이중 꼬임, 0.5초 실패 위험) → **"자식을 기억으로 알아보나. 그냥 알지."** 잠정 교체 — 도윤의 머리 언어(기억·기록·절차)를 인화의 몸 언어(손·자식)로 격파. 실물 대면 직전 확신을 심어 "……아니야"의 낙차 강화. 탈락 후보 보존: "기억이 나면, 그게 탈이지" / "남의 애 얼굴이 기억날 리가 있나" (낭독 후 최종 확정)

- **겹침 전환 (연출 원칙 3):** 1장 끝말 "누구니?" → 2장 첫말 도윤의 전화 "누구시라고요?" / 2장 끝 허밍 → 3장 첫 라디오 노래(사랑했지만)로 소리가 포개짐 — 허밍이 노래에 스며드는 전환 제안
- **은행·후보 사용:**
  - 확정 1호 "먹고 살았나" — 원문 그대로 (한때 붙였던 백규 꼬리는 담백 패스에서 제거). 관공서의 환대(믹스커피) 직후 배치 — 온기의 정점에서 균열 직전 (감동원칙 1)
- **담백 패스 (2026-07-12, 배우님 지침 "인간의 언어로, 뭘 담으려고 하지 마라"):** 명찰 문장 전면 제거 — "봄이 오는 값" / "남의 집 신발 사십 년" / "나라가 주는 건 다 달아" / "절차는 종이가 밟는 거고" / "그대로지, 그대로라서 아니야" / "종이 말고 그림을 봐요" → 전부 사람 말로 교체 또는 삭제. 삼킨 말은 대사가 아니라 몸짓(가리키다 거둔 손)으로. 허풍 1회 투입(관장이 나 알아 — 3장에서 뒤집힘). 의미는 이 노트에만 적는다 — 대사에는 상황만
  - 변주 W "거짓말로 그린 게 티가 나니" — 코다에 배치 (정본 2-2 지정 자리). "딴 데 정신이 팔려서"가 이날 사건과 접속
- **심은 복선:**
  - **"오랜만이—" 인사가 입에서 죽는 비트** — 위작 대면 7단계(정본 2-2)의 1단계 '반가움'을 무대화. 직전 도판들의 인사가 깔아둔 기대 위에서 끊김 — 확정 2호 "나는 뭘—"과 같은 미완성 문장 문법
  - "그대로라서 아니야" + 꽃을 가리키다 삼킨 말 → 3장 후보 AB("어머니 관의 꽃")의 뇌관. ⚠️ AB 표기 수정 필요: "이고 있는 꽃" → **"귀 위에 꽂은 꽃"** (1장 "왼쪽 귀 위에 흰 꽃"과 통일)
  - "눈 밑에 붓 두 번/세 번" — 손의 증거 = AB "떨린 손"의 예습. 마음의 언어를 기법의 언어로 말하는 인화
  - "마당 목련, 황사만 지나면 그릴 거야" → 후보 AC "그 봄엔 목련을 못 그렸어"(5장)의 플랜트 — 사건이 그녀의 4월을 삼킨다
  - 도윤 "물건입니다" 실언 → 제도의 언어가 그의 입에 이미 들어와 있음 (3장 화법 이행의 씨앗)
  - 백규 "자네 그림이구먼" → 가장 가까운 사람의 첫 흔들림 (3장 머뭇거림의 씨앗)
  - 도윤의 밥그릇: "실장 달고 처음 벌인 일" — 사업 실패 = 그의 몰락 → 3장에서 제도 편에 설 수밖에 없는 경제적 근거
