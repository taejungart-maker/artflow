# 🎬 쇼츠 8회차 기획안 — 퀼트 산수 시리즈

> **컨셉**: "한국 전통의 재발견 — 천으로 그린 산수"
> **소재**: 인사동 라메르 갤러리 1층 퀼트 산수 연작 9점
> **타겟**: 미술 애호가, 한국 문화 콘텐츠 시청자, 공예 관심층
> **포맷**: 9:16 세로, 30~60초

---

## 🎯 시리즈 컨셉

| 항목 | 내용 |
|---|---|
| **시리즈 제목 후보** | "천으로 그린 우주" / "壺中天地 — 항아리 속의 별세계" |
| **공통 인트로** | "이게 그림이 아니라 천이라면?" (1.5초 훅) |
| **공통 BGM** | 거문고·대금·해금 (모던 어레인지) |
| **공통 자막체** | 명조체 + 한자 병기 |

---

## 📺 회차별 기획

### EP.1 — 첫 충격 (Hook)

| 요소 | 내용 |
|---|---|
| **훅** | "이게 그림이 아니라 **천**이라면?" |
| **구성** | 풀샷 → 슬로우 줌인 → 바늘땀 클로즈업 |
| **반전 포인트** | 0:08초 "퀼트입니다" 자막 |
| **CTA** | "이 시리즈 8개 더 있어요 → 팔로우" |

---

### EP.2 — 텍스처 ASMR

| 요소 | 내용 |
|---|---|
| **훅** | "수묵의 농담을 천으로 어떻게?" |
| **구성** | 4K 슬로우 텍스처 클로즈업 컷 모음 |
| **사운드** | 바느질 소리 + 천 결 만지는 ASMR |
| **자막 키워드** | "결" "땀" "농담(濃淡)" |

---

### EP.3 — 산수 해체 (Mapping)

| 요소 | 내용 |
|---|---|
| **훅** | "왜 산수가 부서져 있을까요?" |
| **구성** | 작품 2 → 산수 단면 하이라이트 → 원형 달 줌인 → 별세계 |
| **메시지** | 입체파(서양) + 산수화(동양)의 만남 |

---

### EP.4 — 달의 변주 (Visual Rhythm)

| 요소 | 내용 |
|---|---|
| **훅** | "8개 작품 속 달, 모두 다릅니다" |
| **구성** | 9작품의 '달'만 빠르게 컷 편집 (1초씩) |
| **마지막** | 마지막 컷 → 달항아리(작품9) 정지 |
| **자막** | "달이 곧 항아리, 항아리가 곧 우주" |

---

### EP.5 — 신선세계 (Storytelling)

| 요소 | 내용 |
|---|---|
| **훅** | "달밤, 누각, 사슴 — 어디로 가는 길일까요?" |
| **구성** | 작품 5(달밤 누각) 천천히 패닝 |
| **나레이션** | "신선들이 산다는 별세계, 천 위에 펼쳐졌다" |
| **BGM** | 대금 솔로 |

---

### EP.6 — 시·서·화의 합 (Cultural Depth)

| 요소 | 내용 |
|---|---|
| **훅** | "작품 안에 글자가 보이시나요?" |
| **구성** | 작품 6 글자 부분 줌인 → 산수 → 달 순회 |
| **교육 포인트** | "詩書畵(시서화) 통합 — 동양 미학의 정수" |
| **자막** | 한자 + 한국어 병기 |

---

### EP.7 — 壺中天地 (호중천지, Philosophy)

| 요소 | 내용 |
|---|---|
| **훅** | "항아리 속에 우주가 있다고요?" |
| **구성** | 작품 7(동굴 속 소나무) + 작품 9(달항아리 산수) 비교 |
| **메시지** | "작은 것 안에 큰 것이 깃든다" |
| **자막** | "壺中天地 — 호중천지" |

---

### EP.8 — 작가에게 (Closing)

| 요소 | 내용 |
|---|---|
