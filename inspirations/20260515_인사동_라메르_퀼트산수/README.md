> **관람일**: 2026-05-14
> **장소**: 인사동 라메르(La Mer) 갤러리 1층

> **배우님 한 줄 감상**: *"수묵화는 농담으로 표현하는 기법이라면, 이 퀼트로 산수를 표현하고 추상으로 단면을 콜라주처럼 풀어낸 작품은 경이로울 따름. 한국의 전통적인 모습이 너무 아름답게 표현되었다."*

| 요소 | 분석 |
|---|---|

| **공통 도상** | 달항아리 / 둥근 달 / 산수 / 구름 / 누각 / 소나무 / 글자(서예) |

| **메시지** | 한국의 정체성을 천(섬유)이라는 일상 매체로 재해석 |

## 🔥 이 작가가 경이로운 이유

| 포인트 | 설명 |
|---|---|
| **매체의 혁명** | 수묵의 농담(濃淡)을 → 천의 결과 두께로 번역 |
| **시간의 누적** | 한 작품 = 수개월~수년의 손바느질 = 명상의 시간 |
| **전통의 해체와 재구성** | 산수를 분해해서 콜라주처럼 재배치 (입체파 + 동양화) |
| **공예 ↔ 순수예술 경계** | 퀼트는 '여성 공예'로 폄하되었던 매체 → 회화의 위치로 격상 |
