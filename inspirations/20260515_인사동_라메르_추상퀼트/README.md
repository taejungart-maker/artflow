## 💎 핵심 메시지 (추정)

> **"형태가 흩어져 자유로워지는 순간"**

| 키워드 | 설명 |
|---|---|
| **流 (흐름)** | 좌상 → 우하로 컬러가 흘러내림 |
| **解體 (해체)** | 빽빽한 컬러가 풀리며 흩어짐 |
| **餘白의 美** | 흰 공간이 작품의 절반 — 동양적 비움 + 서양적 추상 |
| **遊戱 (유희)** | 무거움 없이 즐거운 톤 |
