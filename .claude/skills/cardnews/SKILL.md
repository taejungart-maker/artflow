# 📇 artflow 카드뉴스 전략 (제작 기술은 `cardnews-producer` 참조)

> **역할 분리:** 글로벌 `cardnews-producer` = 어떻게 만드나 (트랙 A: HTML→Playwright PNG / 트랙 B: 캔바 대량 제작).
> 이 스킬 = **artflow가 무엇을, 언제, 왜 만드나.**

---

## 1. 금고 전략 — 《감정》은 아낀다 ⭐

- **《감정》 티저는 공개 금지** — 개막 6~8주 전, 티켓 오픈과 함께 투하 (관심→예매 전환)
- 이유: ①시그니처 대사는 초연 객석에서 처음이어야 함 ②공연 정보 없는 관심은 6~8주면 소멸 ③완성 전 소재·각도 노출 ④허구화 방어막(전면 허구 명기)이 갖춰진 뒤 공개가 순서
- 시안 자산 (금고 보관, `works/카드뉴스/감정_티저_v1.html`): 시그니처 대사 오프닝 → 인물(그린 사람↔그렸다는 사람) → **1991 가상 신문** 컨셉 (최종안)
- 예외: 지원사업·제작 파트너 **비공개 피칭 자료**로는 지금도 사용 가능

## 2. 2트랙 — 계정은 지금부터 키운다

| 트랙 | 내용 | 주기 |
|------|------|------|
| **본진 (정체성)** | 태정 작품 + 아트노트 한 줄 | 주 1회 |
| **확산 (교양)** | "거장의 빛과 색" — 매회 1거장 1원리 | 주 1~2회 |

- 교양 팔로워(미술 감성) = 미래의 《감정》 관객 — 잠복 마케팅
- 작품 트랙 전제: 작품 이미지 확보 (2026-07-19 현재 갤러리 폴더 1점뿐 — 배우님 수집 대기)

## 3. "거장의 빛과 색" 시리즈 큐

- 포맷 고정: 표지(이름+한 문장 논지) → 본문 4~5장 → **속설 교정 1장** → 클로징(다음 예고 "?")
- 1화 렘브란트 "빛은 쌓는 것" (시안: `works/카드뉴스/빛과색_01_렘브란트.html`)
- 큐: ② 소른(4색 팔레트의 진실) → ③ 벨라스케스(빛이 주인공을 정한다) → ④ 모네 → ⑤ 페르메이르 → 동양화 빛과색·노탄 구도 편
- 근거는 `knowledge/` 빛과색 KB의 **✅ 검증 항목만**. 명화 이미지 대신 도해·미드저니 생성 이미지
- 카피 톤: 담백·구어 — 상징으로 그럴듯하게 쓰지 않기 (극작 헌법과 동일)

## 4. 디자인 교훈 (2026-07-19, 배우님 판정 "허접" ×3회)

- **CSS 자작 그래픽만으로는 'PPT 천장'을 못 넘는다** — 진짜 이미지 + 제대로 된 폰트가 있어야 함
- artflow 우선순위: ① 캔바 템플릿 (트랙 B) ② **미드저니(배우님) 이미지 × 모루 조판** (트랙 A + Pretendard 폰트 스택) ③ HTML 자작은 구성·카피 검토용 시안으로만
- 이미지 협업 절차: 모루가 장별 미드저니 프롬프트 표 제공 → 배우님 생성 → `works/카드뉴스/assets/` 투입 → 모루 조판·PNG

## 5. 게시 경로 (artflow 현황)

- 현재: 수동 (모루 PNG+캡션 → 배우님 업로드)
- 목표: 인스타 프로페셔널 계정 + Meta Graph API → 모루 직접 게시 (캐러셀 10장 한도) — 설정 미착수
- 캔바 MCP(`mcp__claude_ai_Canva__*`) 연결 확인됨 — 모루가 캔바 생성·내보내기 직접 구동 가능성, 테스트 과제
