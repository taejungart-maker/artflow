배우님이 2026-05-16 MCP+Apify 워크플로우를 학습하시고, **유튜브·인스타에 직접 적용**하시기로 결정. 4 모루 가족 전체의 공유 자산이 될 도구.

**Why:** 배우님 명시 — "내가 유튜브 인스타에 적용해야하니까". 사업 확장의 핵심 인프라가 될 가능성. 영상 제작·쿠팡 마케팅·미술 작품 영감 모두에 활용 가능.

**How to apply:**

## 🎯 모루별 활용 우선순위

| 모루 | 우선순위 | 활용 방향 |
|---|---|---|
| **SNS 홍보영상 모루** | 🔥🔥🔥🔥🔥 최우선 | 클라이언트·경쟁사 인스타·유튜브 분석 → 영상 기획 단계 자동화 |
| **쿠팡 (mbc_final)** | 🔥🔥🔥 중간 | 경쟁 셀러·브랜드 SNS 모니터링, 트렌드 추적 |
| **artflow (AI 아트)** | 🔥🔥 보조 | 미술 작가·전시 인스타 자동 모니터링 (영감 자료) |

## 🔧 구축 단계 (배우님 진행 시 가이드)

1. **Apify 계정 생성** → API 토큰 발급
2. **Claude 커넥터 설치**: Customize → Connectors → Apify MCP
3. **시범 운영**: 한 클라이언트(SNS 홍보영상) 또는 한 경쟁사(쿠팡) 1주일 분석
4. **스킬 패키징**: `/instagram-analyzer`, `/youtube-analyzer` 같은 명령어로 스킬화
5. **효과 검증 후** → 다른 모루들도 도입
6. **클로드 코워크 결합** (선택): 매일 자동 리서치 → 카톡 발송 자동화

## 📋 artflow가 도와줄 수 있는 영역

- 미술 작가 인스타 모니터링용 스킬 설계
- 영감 자료 자동 수집 → `inspirations/` 폴더 영속화
- 라메르 갤러리 작가 발견 시 자동 알림 (이런 식)
