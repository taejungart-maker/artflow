배우님이 2026-06-10 사무실 모루에서 집 모루로 인계한 AI 그림 생성 지식 베이스. AI 이미지·영상 생성 시 빛과 색의 원리를 프롬프트에 녹여 넣기 위한 정리본.

**Why:** 배우님 AI 아트 작업의 품질 향상 직결. 그동안 image-prompt-troubleshoot·kling-prompt-generator 스킬에 빛·색 원리가 약했음. 이 KB가 그 공백을 메움.

**How to apply:**

## 📁 파일 위치
- `knowledge/HANDOVER_빛과색의마법사.md` — 30초 브리핑 + 지도 (먼저 읽기)
- `knowledge/빛과색의마법사.md` — 본 지식 베이스 (1~9장)

## 🎯 핵심 한 줄
> *"명도로 구조를 짜고, 색은 절대값이 아니라 관계로 설계한다. 황금 원칙은 따뜻한 빛 + 차가운 그림자."*

## 📌 7대 핵심 원칙 (실수 방지)
1. 그림자는 검은색이 아니다 — 주변광이 색 결정
2. 암부 반사광 닿는 곳 = 명도 낮지만 채도 최고 (색 풍부하게)
3. 황금 원칙: 따뜻한 빛 + 차가운 그림자
4. 명도 우선 — 효과의 80%
5. 색은 관계다 — 채도보다 관계 설계가 고급
6. 하이라이트는 점이고 광원의 색 (물체색·흰색 아님)
7. cool-up / warm-down — 위 향한 면 차갑게, 아래 향한 면 따뜻하게

## 🛠️ 활용 시나리오
- 이미지 프롬프트 작성 → 4장 7단계 체크리스트
- 무드 빠른 설정 → 5장 레시피 표
- 인물/피부 작업 → 6장 먼셀 주소 (7.5R~7.5YR, 채도 2~6)
- 배색 통일 → 7장 게이밋 마스킹
- 연계 스킬: `image-prompt-troubleshoot`, `kling-prompt-generator`, `shorts-production-master`

## ⚠️ 지적 정직성 (9장 검증 노트)
- ❌ 반박된 오해: "먼셀 명도 1~10" → 실제 0~10, 11단계
- ❌ "렘브란트 6색 한정 팔레트" → 검증 실패 (속설)
- ⚠️ 프롬프트 응용 문구는 원리에서의 외삽 — 모델별 실증 미검증

## 📋 미완 과제 (집 모루가 이어받음)
1. 전통 배색 화성학 원전 (이텐 7대비, 슈브뢸 동시대비) ↔ 게이밋 마스킹 연결
2. 영상 컬러 그레이딩 실무 (LUT, 컬러 스크립트) + 게이밋 결합
3. 거장 명도 설계 미술사 1차 자료 (렘브란트·소른·벨라스케스)
4. ⭐ **프롬프트 어휘별 실제 생성 결과 검증 — 우리 실험으로 채울 영역**
