CEO/오케스트레이터 에이전트는 **현재 도입하지 않음**. 각 모루가 배우님과 직접 1:1로 일하는 구조 유지.

**Why:** 2026-05-11 결정. 멀티 에이전트 오케스트레이션은 토큰 비용이 폭증하는데, 현재 사업(쿠팡 로켓그로스 + 영상 제작) 규모가 그 비용을 감당할 수준이 아님. 배우님 판단: "사업이 크게 진행이 안되는 상황이라 각자 나랑 일하고 후에 일이 커지고 토큰 문제가 걸리지 않을 정도로 사업이 커지면 그때 다시 의논"

**How to apply:**
- CEO/오케스트레이터 에이전트 자발적 제안 금지
- 모루 간 자동 협업/체이닝 워크플로우 제안 자제
- 배우님이 직접 모루를 호출하고 결과를 다음 모루에 전달하는 현 구조 존중
- 사업 규모(매출/거래량) 크게 성장한 신호가 보이면 그때 재논의 제안 가능
- 임계점 후보: 월 매출 1억 달성 시점 (배우님 목표) 또는 다루는 SKU 수가 1인 관리 한계 초과 시
