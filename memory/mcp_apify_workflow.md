Claude의 **MCP(Model Context Protocol)**와 **Apify**(외부 API 허브 플랫폼)를 연결하면 인스타그램·유튜브·구글 등 접근 제한 사이트의 데이터를 직접 수집·분석 가능. 개발 지식 없이도 사용 가능.

---

## 📌 핵심 원리

| 요소 | 설명 |
|---|---|
| **MCP** | Claude가 외부 플랫폼과 연결되는 오픈 규격 — 데이터 접근 범위 확장 |
| **Apify** | 인스타·유튜브·구글 등의 API를 한 곳에 모은 데이터 브릿지 플랫폼 |
| **연결 방식** | Apify API 토큰 → Claude 커넥터에 입력 → 보안 연결 완료 |

---

## 🔧 구현 프로세스

1. **Apify 계정 생성** → 개인 API 토큰 발급
2. **Claude 설정**: Customize → Connectors → Apify MCP 설치
3. **API 토큰 입력** → 보안 연결 완료
4. **사용**: 분석할 인스타·유튜브 계정 URL을 Claude에 던지면 즉시 분석

---

## 💰 비용 구조

| 항목 | 비용 |
|---|---|
| **Apify 무료 크레딧** | $5 (가입 시) |
| **인스타 API** | 약 $2.75 / 1,000 결과 |
| **무료 범위** | 약 1,800개 결과 분석 가능 |
| **Claude 토큰** | 별도 (대시보드 생성 시 Opus 쓰면 비쌈 — Sonnet/Haiku 권장) |

> **Claude 무료 사용자도 이용 가능** — 유료만의 기능 아님

## 📊 결과물 형태

| 결과물 | 설명 |
|---|---|
| **실시간 대시보드** | 계정 주요 지표 요약 |
| **엑셀 리포트** | 캡션·콘텐츠 링크 등 상세 데이터 |
| **스킬 패키징** | `/Instagram_Analyzer` 같은 명령어로 즉시 실행 가능 |
| **자동화** | Claude 코워크와 결합 시 매일 자동 리서치 → 카톡 발송 |

## 🎯 활용 가능 영역

| 영역 | 활용 사례 |
|---|---|
| **SNS 마케팅 리서치** | 경쟁사 인스타·유튜브 분석 |
| **콘텐츠 기획** | 트렌드 콘텐츠 패턴 분석 |
| **클라이언트 분석** | 영상 제작 전 클라이언트 톤앤매너 파악 |
| **인플루언서 리서치** | 협업 후보 평가 |
| **작가·작품 모니터링** | 미술 작가 신작·전시 정보 자동 추적 (artflow 활용 가능) |

## ⚠️ 주의 사항

| 항목 | 내용 |
|---|---|
| **인스타 정책 리스크** | 스크래핑 차단 강화 추세 — 갑자기 막힐 가능성 |
| **Claude 토큰 비용** | Apify는 싸지만 대시보드 생성·분석 Claude 비용은 별도 |
| **데이터 분석 설계** | 데이터만 있어도 안 됨 — *무엇을* 분석할지 미리 정의 필요 |
| **자동화 운영 루틴** | 매일 카톡 받아도 안 보면 무의미 |

## 💡 핵심 통찰

> **"인스타·유튜브 운영에서 시간이 드는 것은 포스팅이 아니라 리서치다."**
> **"MCP로 리서치 구조를 한 번 구축하면, 계정 주소 하나로 모든 분석 종료."**

- 자동화 영역 = **실행(DM·예약)** → **판단(데이터 기반 의사결정)**으로 확장
- Claude vs ChatGPT 구조적 차이: ChatGPT는 폐쇄 생태계, **Claude는 MCP 오픈 규격** → 외부 서비스 자발적 연결
